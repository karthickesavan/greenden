Greenden - Plant Website

A simple and responsive plant website created using HTML and Tailwind CSS. This project is designed as a beginner-friendly frontend project to practice Tailwind CSS and responsive web design.

About the Project

Greenden is a simple plant shop website where users can explore different plants, view products, and contact the store.

The project contains three pages:

Home - Introduction, About Us, Best Sellers, Customer Reviews and Newsletter
Products - Collection of available plants
Contact - Simple contact form

How to Run
Download or clone this repository.
Open the project folder in VS Code.
Open index.html.
Right-click the file and select Open with Live Server.
Use the navigation bar to visit:
Home
Products
Contact
